바쁘신 중에 질문 주셔서 감사합니다. 네 가지를 순서대로 정리했습니다. 그림이 있는 자세한 사용법은 https://www.ai-make.co.kr/manual/ 에 있습니다. 그 매뉴얼의 「우리홈페이지주소」 자리에 www.es-company.co.kr 를 넣어 읽으시면 됩니다.

1. 홈페이지 활용 방법 — 일하는 순서대로

  1. 손님이 「얼마예요?」 하면 전화로 받지 말고 www.es-company.co.kr/quote.html 을 문자 · 카톡으로 보내세요. 손님이 천막 · 테이블 · 의자 수량을 골라 보내면 esgroup0102@naver.com 으로 정리된 문의 메일이 옵니다. 홈페이지 「견적문의」 폼으로 온 것도 같은 메일함입니다.
  2. 견적서 발행. 메일 속 「이 문의로 견적서 작성」을 누르면 손님이 고른 품목이 채워진 관리자 견적서가 열립니다. 단가를 넣고 「이메일」 로 보내거나 「인쇄 · PDF 저장」. 직인이 자동으로 찍힙니다. 「견적서 저장함」 에 담아 두면 폰과 PC 어디서든 다시 불러옵니다.
  3. 전자계약. 견적서에서 「이 견적으로 계약서 작성」 → 계약 내용 확인 → 「고객 서명 링크 만들기」 → 링크를 문자 · 카톡으로. 손님이 폰에서 서명하면 서명본 PDF 가 대표님 메일과 손님 메일로 갑니다. 입금 계좌(하나은행)와 직인은 이미 들어 있습니다.
  4. 행사 뒤. 현장 사진을 upload.html 로 올리고(4번 참고), 「이 견적으로 거래명세서 작성」으로 명세서를 보냅니다.
  5. 홈페이지 글 · 사진을 바꾸고 싶을 때. 수정 모드 주소로 들어가 글자를 눌러 고치고 사진을 바꾼 뒤 「수정 내용 보내기」. 보내 주시면 큰길브리지가 보통 1영업일 안에 반영합니다. 디자인이 망가질 걱정은 없습니다.
대표님이 하실 일은 ①~④ 와 블로그 글, 큰길브리지가 하는 일은 수정 반영 · 검색 관리 · 도메인 · 서버 관리(1년 케어팩, 2027-09-15 까지)입니다.

2. 구글 · 네이버 최적화 후 관리 방법

이미 해 둔 것

  • 네이버 서치어드바이저 · 구글 서치콘솔에 등록하고 사이트맵(31쪽) · RSS 를 제출했습니다.
  • 행사 가이드 글 10편, 지역 페이지 14곳(청주 · 충주 · 제천 · 세종 · 대전 …), AI 검색용 안내 파일을 넣었습니다. 「청주 운동회 천막 렌탈」처럼 지역 + 행사 + 품목으로 찾는 손님을 겨냥한 구성입니다.
  • 검색에 제대로 올라오기까지 보통 2~8주 걸립니다. 첫 달은 결과가 적어도 정상입니다.

대표님이 꾸준히 하실 것 (이게 순위를 올립니다)

  1. 네이버 블로그 글을 계속 쓰세요. 행사 끝날 때마다 한 편, 적어도 한 달에 2~4편. 4번의 글 자동 작성을 쓰면 5분이면 됩니다. 글 끝에 홈페이지 주소를 꼭 넣으세요. 블로그와 홈페이지가 서로 연결되면 둘 다 올라갑니다.
  2. 네이버 스마트플레이스에 등록하세요. 「청주 행사용품 렌탈」 지도 검색에 나오게 하는 가장 빠른 길입니다. 대표님 네이버 계정으로 상호 · 주소 · 전화 · 홈페이지 주소 · 사진을 넣습니다. 어려우시면 전화 주시면 같이 해 드립니다.
  3. 후기를 모으세요. 행사 끝난 손님에게 네이버 후기 한 줄을 부탁하세요. 홈페이지의 후기 3개는 지금 예시 문구입니다. 실제 후기 문장 3개를 보내 주시면 바로 바꿔 드립니다.
  4. 한 달에 한 번 직접 검색해 보세요. 네이버 · 구글에서 「청주 천막 렌탈」 「충북 행사용품 렌탈」 「이에스컴퍼니」. 몇 쪽에 나오는지 보시고 변화가 없으면 알려 주세요.
  5. 하지 말 것. 같은 글을 복사해 여러 번 올리기, 남의 사진 쓰기, 돈 주고 후기 사기. 네이버가 블로그를 낮게 평가합니다.

큰길브리지가 계속 하는 것

  • 검색 등록 상태 점검과 수집 요청, 새 글 · 지역 페이지 추가, 도메인(2027-10-07 만료) 갱신 안내.
  • 사진 올리기 서버 · 계약 서버 · 문의 서버 관리. 이상이 보이면 저희가 먼저 연락드립니다.

3. 콜백 문자 · 디지털 명함 활용 방법

콜백 문자가 무엇인가

전화를 받고 끊으면, 상대 폰에 내 모바일 명함이 문자로 날아가는 기능입니다. 큰길브리지가 만든 안드로이드 앱 「큰길행사알림」이 합니다. 행사장에서 받은 전화는 이름 · 번호를 받아적을 틈이 없는데, 이 문자 한 통으로 상대 폰에 이에스컴퍼니 연락처 · 홈페이지 · 카톡이 남습니다. 문자 요금은 대표님 통신사 요금제를 따릅니다(한 통 글이면 보통 무료 범위).

기본 문자 글: 「통화 감사합니다. 명함 보내드립니다.」 + 명함 주소. 글은 앱에서 바꿀 수 있습니다. 45자를 넘기면 여러 통으로 쪼개져 요금이 배가 되니 짧게 두세요.

설치하기 (안드로이드 폰, 5분)

  1. 폰 인터넷 창에서 https://큰길이벤트.com/app/ 를 엽니다.
  2. 이름 · 번호 · 직군(렌탈 · 설치) · 지역(충청 · 대전)을 고르고 「등록하고 앱 내려받기」를 누릅니다. 그러면 「앱 내려받기 (APK)」 단추가 나옵니다. 약 3MB 입니다.
  3. 내려받은 파일을 눌러 설치합니다. 「출처를 알 수 없는 앱」을 허용하겠냐고 물으면 허용, 「기기에 위험을 줄 수 있다」 경고가 뜨면 「무시하고 설치」. 구글이 전화 · 문자 권한을 쓰는 앱에는 다 띄우는 경고입니다. 이 앱은 통화 내용 · 번호를 폰 밖으로 보내지 않습니다.
  4. 그래도 막히면: 플레이스토어 앱 → 오른쪽 위 프로필 → Play 프로텍트 → 톱니 → 「유해한 앱 검색」을 잠시 끄고 설치한 뒤 다시 켭니다.

콜백 문자 설정하기 (앱 안 「콜백 문자」 칸)

  1. ① 내 전자명함 주소에 https://www.ai-make.co.kr/card/qc127i/ 를 붙여넣습니다. 명함 페이지의 「명함 링크 공유」에서 복사하면 됩니다.
  2. ② 보낼 글은 기본 글을 그대로 두거나 「이에스컴퍼니 박미배입니다. 통화 감사합니다. 명함 보내드립니다.」처럼 짧게 고칩니다. 아래에 「한 통」이라고 나오면 됩니다.
  3. ③ 어떻게 보낼까요
    • 「보내기 전에 물어보기」: 켜 두면 통화가 끝날 때 「명함을 보낼까요?」 창이 뜨고, 보내기를 누르면 문자 앱이 상대 번호와 글이 채워진 채 열려 전송만 누르면 됩니다. 끄면 앱이 바로 보냅니다(처음엔 켜 두시길 권합니다).
    • 「걸려온 전화만」: 내가 건 전화에는 안 보냅니다.
    • 「모르는 번호에만」: 주소록에 있는 분에게는 안 보냅니다. 끄려면 연락처 권한이 필요합니다.
    • 같은 번호에는 30일 안에 다시 보내지 않고, 하루 한도가 있습니다. 받지 않은 전화에는 보내지 않습니다.
  4. 「전화 확인 앱으로 지정하기」를 누르고 안드로이드가 물으면 「기본으로 설정」. 상대 번호를 받기 위한 것이고, 전화를 막거나 조용히 하지는 않습니다. 안드로이드 10 이상에서만 됩니다.
  5. 「화면 위에 띄우기 켜기」를 누르고 허용합니다. 안 켜면 물음이 알림으로만 떠서 놓치기 쉽습니다.
  6. 「콜백 문자 켜기」. 「켜짐 · 통화가 끝나면 물어봅니다」로 바뀌면 끝입니다. 직원 폰에도 같은 방법으로 깔고 같은 명함 주소를 넣으면 됩니다.

시험해 보기

다른 폰으로 대표님 폰에 전화를 걸어 받고 끊어 보세요. 「명함을 보낼까요?」 창 → 보내기 → 상대 폰에 문자와 명함 링크가 오면 됩니다. 며칠 쓰다 조용해졌다면 설정 → 배터리 → 큰길행사알림 → 「제한 없음」으로 바꿔 주세요.

디지털 명함 활용

  • 명함 주소 https://www.ai-make.co.kr/card/qc127i/ 를 카톡 프로필 소개, 문자 서명, 인스타 프로필 링크, 네이버 블로그 프로필에 넣으세요. 종이 명함 · 차량 · 현수막에는 QR 로 넣으면 좋습니다(QR 그림은 요청하시면 만들어 드립니다).
  • 손님은 명함에서 전화 · 문자 · 연락처 저장(주소록에 이에스컴퍼니가 바로 저장) · 카카오톡 ID · 이메일 · 지도 열기를 한 번에 할 수 있고, 좋아요 · 댓글도 남깁니다.
  • 명함의 사진 · 직함 · 소개 문구를 바꾸고 싶으시면 말씀만 주세요. 주소는 그대로 두고 내용만 다시 발행합니다.

앱에는 콜백 문자 말고도 카톡방 구인 글 알림(내 직군만 골라 울림)과 새 행사 입찰 알림(나라장터, 하루 한 번)이 함께 들어 있습니다. 필요 없으면 앱 안에서 끄면 됩니다.

4. 자동 문구 만든 뒤 블로그 · 페이스북 · 인스타에 올리는 법

먼저 글 만들기 (폰에서 5분)

  1. www.es-company.co.kr/upload.html 을 엽니다. 즐겨찾기 해 두세요.
  2. 「갤러리 항목」(학교행사 · 체육대회 · 축제 · 기업행사 · 관공서 · 실내행사)을 고르고 행사명 · 날짜 · 장소를 적습니다. 「행사 설명」에 지역 + 행사 종류 + 설치한 품목을 한두 문장 쓰면 글이 훨씬 좋아집니다. 예) 청주 ○○초 가을 운동회. 학년별 캐노피천막 12동과 본부석 몽골텐트, 테이블 · 의자 200조를 전날 설치했습니다.
  3. 「사진 선택」으로 현장 사진을 여러 장 고르고, 표지로 쓸 사진에 「대표로」.
  4. 업로드 비밀번호를 넣고 「갤러리에 올리기」. 끝나면 홈페이지 현장사진 페이지에 자동으로 붙습니다.
  5. 아래 「04 블로그 · 인스타 글 자동 작성」이 열립니다. 사진 없이 글만 먼저 보려면 「블로그 · 인스타 글 미리 만들기」.

네이버 블로그

  1. 제목 후보 5개 중 하나 옆의 「복사」.
  2. 네이버 블로그 앱 → 글쓰기 → 제목 칸에 붙여넣기.
  3. 돌아와서 「본문 복사」 → 블로그 본문에 붙여넣기.
  4. 본문의 「― 사진 ―」 자리에 사진 단추로 현장 사진을 넣습니다(그 글자는 지웁니다).
  5. 본문 맨 끝 # 줄은 본문에서 지우고, 발행 설정의 태그 칸에 하나씩 넣습니다.
  6. 한두 문장은 그날 이야기로 바꿔 쓰세요(날씨, 손님 반응, 어려웠던 점). 매번 똑같은 글은 네이버가 싫어합니다.
  7. 전체공개로 발행. 글 끝의 홈페이지 주소는 그대로 두세요.

인스타그램

  1. 「인스타그램 문구」 아래 「문구 복사」.
  2. 「사진과 함께 공유」를 누르면 폰 공유창이 뜹니다. Instagram을 고르면 사진이 넘어갑니다. 안 뜨면 인스타 앱에서 직접 사진을 고르세요(여러 장 가능).
  3. 글 칸에 붙여넣기 → 게시. 해시태그 30개까지는 그대로 써도 됩니다.
  4. 인스타 프로필의 링크는 www.es-company.co.kr/quote.html 로 두세요. 글 속 「프로필 링크 → 자동 견적서」가 그 링크를 가리킵니다.

페이스북

  1. 인스타 문구를 그대로 쓰되 해시태그는 3~5개만 남기고 지웁니다. 페이스북은 해시태그가 많으면 오히려 안 좋습니다.
